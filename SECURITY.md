# Security policy

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for this repository
(**Security → Report a vulnerability**). Include steps to reproduce, the affected
version/commit and potential impact. Do not include real API keys, credentials or
private article data in reports.

Never commit `.env` files, API keys, database dumps or exported intelligence data.
If you accidentally expose a key, revoke/rotate it with the provider immediately;
deleting it from a later commit does not remove it from Git history.
